## Info
- URL options: ?mood=day|golden|sunset|dusk|night, ?free (start in free fly), ?q=low (lighter for tablets), ?big=0 (start with big clouds off).
- Controls: drag = look, WASD/arrows = move, Shift = fast, Q/E = down/up. Any input stops the tour; Tour button restarts it.
- Trees: trees/manifest.json = { "trees": [ { "file": "acacia.glb", "height": 9, "weight": 3, "sink": 0.2 } ] }. height in metres, weight = how common, sink = how far the trunk goes into the ground.
